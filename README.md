# 👨‍🎓 EBAC Módulo 34 - Testes E2E com Cypress

## E2E

Neste módulo aprenderemos a escrever testes E2E (end-to-end, de ponta a ponta). Neste tipo de teste, buscamos interagir com uma aplicação da mesma maneira que o usuário final iria fazer. É considerado o tipo de teste mais complexo, pois depende do funcionamento do Front-End e Back-End, quando temos integração com API.

## ✏️ Aula 1 - Configure o Cypress

- conceituar a ferramenta Cypress;
- instalar o Cypress na máquina;
- começar a usar o Cypress para testes automatizados.

## ✏️ Aula 2 - Selecione elementos

- usar a função describe para agrupar testes;
- aprender a função "it";
- recuperar elementos com a função get do Cypress;
- apresentar o Cypress para o VScode para usar o autocomplete;
- usar relações hierárquicas;
- construir teste da filtragem.
